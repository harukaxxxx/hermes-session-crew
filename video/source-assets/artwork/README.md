# Norse avatar artwork

These two sets preserve the original generated atlas, fifteen 256 × 256 avatar
crops per set, and contact and QA sheets. The color atlas is an AI-generated
edit of the original atlas. The original generation used the Hermes Agent
homepage artwork as a visual reference; the Desktop artwork and repository
banner were also studied. The references and generation history are described
in the original source manifests and notes, which still require archival review.

These are independent generated illustrations, not an official asset pack.
No official authorization or endorsement is claimed. The visual reference
alone is not evidence of permission to use third-party artwork.

The original source paths were `SessionCrew-Demo/artwork/norse/` and
`SessionCrew-Demo/artwork/norse-color-v2/`; filenames and image bytes are
preserved here. Runtime screenshots and non-image source records are not part
of this initial image-only archive.
